
## Props Immutability

- Props get passed to the Components form Parent Component
- Props are Immutable in React
- Means, cannot be changed inside the Component
- So if Props are immutable, How are we going to maintain the Component Data that may change over time ?

- Every React Component return the JSX , which describes the User Interface
  
## State
  
- State is managed within the Component
- State of a component can be changed
- useState Hook will be used for Functional Component , where as props - for Functional Components
- this.state - will be used for Class Components, where as this.props  - for Class Components


## Summary

- Both Props and State hold the information that impact the User Interface in the Browser.
- State - an object that is privately maintained inside a component
