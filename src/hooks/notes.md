## Hooks in React

- Introduced in `v16.7.0-alpha`
- State or life-cycle hooks exclusive to  Class Components can also be used in Functional Components
- So, We can say that the Functional Components are not Sateless 
- So Now, We only refer Component types as `Functional Components` and `Class Components`
  
- In order to understand Hooks in React, we first make sure to understand the Sate, Life-Cycle hooks, and `this` binding concepts in Class Components
